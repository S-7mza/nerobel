# Nerobel Group — Official Web Platform

Modern, responsive web platform for **Nerobel Group**, exclusive distributor in Morocco for premier heating, sanitary, and thermal comfort brands: **Theros** and **Eurogas**.

---

## 🌟 Exclusive Brand Portfolio

- **Theros**: Exclusive distribution in Morocco. Next-generation smart electric water heaters with Wi-Fi connectivity, Pro-Slim eco-performance, and designer bath/sanitary fixtures.
- **Eurogas**: Exclusive distribution in Morocco. High-efficiency gas water heaters and heating boilers equipped with patented ODS safety systems.
- **Nerobel**: Premium consumer technology, OLED smart displays, and intelligent household appliances.

---

## 🚀 Key Features

- **Multilingual Support**: Real-time language switching (French, Arabic RTL, English).
- **Theme Engine**: Instant Dark Mode and Light Mode switching with system preference detection.
- **Interactive Tracking**: Direct after-sales service (SAV) status and warranty lookup tool.
- **Distribution Network Finder**: Searchable, filterable nationwide showroom and partner locator.
- **Professional B2B Portal**: Dedicated distributor onboarding, technical datasheets, and certification downloads.
- **Zero Heavy Dependencies**: Built with standards-compliant HTML5, modular Vanilla CSS, and lightweight Vanilla JavaScript for blazing-fast load times.

## 📁 Project Structure

```text
nerobel/
├── index.html                 # Corporate homepage with interactive hero & showcases
├── brands.html                # Brand ecosystem & technical specifications
├── b2b.html                   # Professional distributor & partner portal
├── sav.html                   # After-sales service & warranty tracker
├── network.html               # Nationwide showroom & partner network directory
├── contact.html               # Customer service & headquarters contact
├── 404.html                   # Branded error page
├── robots.txt                 # Search engine crawler instructions
├── sitemap.xml                # SEO sitemap
├── assets/
│   ├── icons/                 # Brand logos and vector SVG icons
│   └── img/                   # High-resolution optimized product imagery
├── css/                       # Modular styles & design tokens
├── js/                        # Theme switching, interactive slider, language & SAV logic
└── scripts/                   # Image optimization and verification automation scripts
```

## 💻 Local Preview

You can preview the platform locally with any static web server:

```bash
# Using Python 3 built-in HTTP server:
python -m http.server 8000
```

Then open your browser at `http://localhost:8000`.
